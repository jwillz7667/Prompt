The audit found and repaired functional billing, AI transport, authentication, and web/iOS
integration bugs. Backend and web production dependencies were upgraded to remove reported npm

## Priority findings repaired

| Area                           | Observed failure                                                                                                                                            | Change                                                                                                                                                                     |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Web checkout                   | `/auth/me` returns `{user}`, but checkout read `user.id` from the outer object. Stripe metadata was missing the owner.                                      | Unwrap the account response, verify billing state before checkout, bind customer/session/subscription to that account.                                                     |
| Duplicate payments             | Multiple sessions could be created before the first subscription webhook saved the customer ID.                                                             | Check Stripe after both customer lookup paths, reuse matching open checkout, expire superseded open links, and deduplicate creation using a stable intent key.             |
| API subscriptions              | Checkout wrote `developerId`, while webhooks read `userId` and acknowledged without activation.                                                             | Read the correct owner; verify customer/product; process item-level periods and modern invoice subscription references.                                                    |
| Renewals and credits           | Duplicate or concurrent webhook deliveries could grant credits repeatedly, reset balances, or revoke newer agreements.                                      | Transactional credit fulfillment, event deduplication, current-state reconciliation, and stale-agreement guards.                                                           |
| Apple purchases                | Receipt replay, missing/expired entitlement data, old restores, and transient verification failures were not consistently handled.                          | Atomic ownership checks, product/expiry/revocation validation, preserved new purchases, retryable server failures, and corrected grace/trial state.                        |
| iOS sign-in                    | Returning Apple identities without email could fail; session IDs were not preserved during refresh; cached profile data could falsely appear authenticated. | Verify Apple signatures/audience/nonce, resolve existing identities first, preserve and rotate sessions, require usable tokens, surface errors, and persist tokens safely. |
| iOS startup                    | SwiftData trapped before its error handler when a shared App Group was unavailable.                                                                         | Use private local storage when the shared container is unavailable, including unsigned simulators.                                                                         |
| iOS history quota              | A thread generation followed by saving its result charged quota and token analytics twice; the last allowed generation could not be saved.                  | Save-only requests no longer enforce generation quota or charge usage. PostgreSQL regressions and a live four-generation/four-save check verify unchanged usage on save.   |
| iOS payments                   | Guests or disconnected sessions could reach payment; restoration failures and activation responses were misleading.                                         | Authenticate and preflight the backend, block an existing Stripe agreement, validate paid activation, retain retryable transactions, and surface restore errors.           |
| AI streaming                   | Response-body timeouts ended too early; interrupted or malformed streams could look successful; async persistence was not awaited.                          | Bound full request/stream lifetimes, validate completion, propagate errors, await persistence, and prevent retry after delivered output.                                   |
| AI cost                        | Image threads required OpenAI plus a separate image-analysis call; clients could influence model/reasoning spend.                                           | Use native DeepSeek Flash vision, remove redundant analysis/context, and keep model/reasoning selection server controlled.                                                 |
| Web enhancement                | The client expected an embedded prompt but the server sends `promptId`; UI style/reasoning fields were stripped by server validation.                       | Normalize the actual stream contract, load saved prompts correctly, preserve readable unsaved output, and translate enhancement controls to supported requests.            |
| Session lifecycle              | Stale refresh/account requests could revive or clear the wrong login; logout left the refresh cookie behind.                                                | Session revision checks, shared refresh, cookie logout, paid-state reset, and a reachable login screen during outages.                                                     |
| Support and configuration      | iOS support sockets omitted authentication and clients pointed at a deleted Railway host.                                                                   | Authenticated socket connections and configurable iOS API endpoint; replacement host in source defaults.                                                                   |
| Dependency and PWA maintenance | Outdated Next.js/PDF/validation/runtime libraries and an obsolete PWA dependency chain had reported vulnerabilities.                                        | Next.js 16 and patched dependencies; a small worker caches only same-origin immutable Next static assets. It never caches private pages or API responses.                  |

pre-existing lint warnings are reported rather than silently disabled.

## AI efficiency decision

Keep DeepSeek Flash as the default. The concrete savings come from removing the extra image-analysis
request, using native image support with the same provider key, avoiding duplicated context, and
disabling paid reasoning for standard requests. This is not a measured quality-equivalent
comparison. See [AI operations and current price sources](../AI-OPERATIONS.md) for token prices,
examples, supported overrides, and transport tests.
